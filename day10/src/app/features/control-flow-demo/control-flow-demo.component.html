2) @else if — Student Grade

Multi-branch
@if (grade === 'A') {
Excellent — Grade A
} @else if (grade === 'B') {

Good — Grade C
} @else if (grade === 'F') {
Fail — Needs Improvement
} @else {
Select a grade to see the result
}

Quick Review

Need Use Old equivalent
Show / hide by condition @if / @else *ngIf
Several exclusive branches @else if nested *ngIf / switch
Repeat a list @for (...; track ...) *ngFor
Empty list UI @empty *ngIf + ng-template
One value → many UIs @switch / @case / @default ngSwitch*
